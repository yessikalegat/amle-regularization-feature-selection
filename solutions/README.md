# Solutions

Reference solutions for the exercises in this repository. Open a solution alongside its source notebook to check your work.

| File | Description |
|---|---|
| [**01 - Bias-Variance Trade-Off**](01_bias_variance_tradeoff.ipynb) | Worked solution: the degree-3 polynomial model, and the code for the Try It tasks (less noise, and degree-3 models on three splits). |
| [**03 - Feature Selection**](03_feature_selection.ipynb) | Worked solution for the feature selection notebook: `SelectKBest`, variance inflation factors, p-values, recursive feature elimination, forward and backward selection, Lasso, and the ANOVA and Cramer's V checks for categorical features. |
| [**04 - Detecting Outliers**](04_detecting_outliers.ipynb) | Worked solution: log-transform the test set, fit the with-outliers and without-outliers models, and compare their performance. |
